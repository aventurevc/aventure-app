# aVenture.vc - Venture Capital Research Platform

aVenture is building the future of venture capital research for information on companies and their investors. Learn more at [aVenture.vc](https://aventure.vc).

## Feature Requests and Bug Reports
You can view/create feature or bug requests in [Github Issues](https://github.com/aventurevc/aventure-app/issues) or by using our [Canny Feature Request Board](https://product.aventure.vc).

## Request Research / Data Updates
If you observe a data point you'd like updated, or would like yourself or your company added, you can do so for free by completing a [data request](https://staging.aventure.vc/forms/request-data-updates).
